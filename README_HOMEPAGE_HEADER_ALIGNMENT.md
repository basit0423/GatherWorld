GATHER WORLD — HOMEPAGE HEADER ALIGNMENT UPDATE

This update adjusts the homepage layout only:
- Gather World brand/name is aligned to the LEFT of the top bar.
- The three-line menu button is aligned to the RIGHT.
- The hero eyebrow, main heading, description, action buttons and member/post stats are centered below the top bar.
- The navigation dropdown remains right-aligned under the menu button.
- Mobile spacing is adjusted for narrow screens.

Install:
1. Back up E:\GatherWorld.
2. Extract this ZIP into a temporary folder.
3. Copy the extracted files into E:\GatherWorld and replace matching files.
4. Keep your existing .env and .venv unchanged.
5. Restart Flask and refresh the homepage with Ctrl+F5.

No database migration is required. This is a CSS-only layout change.
