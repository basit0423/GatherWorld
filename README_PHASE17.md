PHASE 17 — GATHER EVENTS & EXPERIENCES
--------------------------------------
- Create and discover meetups, workshops, conferences, online events, cultural
  activities and sports events.
- Event detail page with UTC start/end timestamps, location, description and
  official website / registration link.
- Logged-in members can RSVP as Going or Interested and remove their response.
- Organizers see RSVP counts. Ticketing, payment and venue operations are not
  included in this phase.
